# Shared Album Intake

## Решение

Shared Albums не анализируются напрямую. Photo Curator создаёт из доступных локальных
renders собственный working album на диске и не записывает его в Photos Library.

## Почему

- Shared items могут не быть assets личной Photos Library.
- Поддержка Shared Albums меняется между версиями macOS и `osxphotos`.
- Прямое изменение общего альбома затрагивало бы других участников.
- Импорт создаёт независимую рабочую копию и делает workflow безопаснее.
- Обычный альбом даёт единый source of truth для анализа.

## Автоматизированный intake

1. Photo Curator показывает Shared Albums отдельно от обычных источников.
2. Пользователь выбирает первые N фотографий, отмеченные кадры текущей страницы
   или все фотографии.
3. Сервис проверяет наличие локальных renders и показывает план без изменения Photos.
4. После явного подтверждения renders копируются во временный закрытый cache.
5. Файлы сохраняются в закрытом persistent-каталоге вместе с atomic JSON manifest.
6. После успеха локальный альбом доступен в общем селекторе как источник проекта.

Прерванную или ошибочную операцию можно повторить. Исходный Shared Album не меняется.

## Важный нюанс качества

Shared Album может содержать уменьшенные версии. Поэтому duplicate leader обязан учитывать pixel count и предпочитать полноразмерный original при прочих равных.

Видео не копируются: доступный Shared Album derivative для видео является JPEG-preview,
а не воспроизводимым исходным видео. UI показывает точное число пропущенных видео.

## Safety fallback

Исходный Shared Album остаётся внешним источником. Ошибка в локальном working album не должна менять публикации участников.

## Capability fallback

```text
Автоматическая локальная копия недоступна: локальное хранилище Photo Curator
недоступно для записи или renders ещё не синхронизированы на Mac.
```

## Не автоматизировать

- iCloud.com browser automation;
- UI scripting Photos;
- переключение System Photo Library;
- сетевое скачивание отсутствующих shared-фото;
- удаление из Shared Album;
- перенос комментариев/likes.
