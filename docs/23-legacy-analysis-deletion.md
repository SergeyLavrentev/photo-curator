# Удаление legacy анализа без album snapshot

Ошибка `Quality Lab learning requires an immutable album snapshot` блокировала удаление
старых анализов с человеческими labels, хотя их можно сохранить без включения в обучение.

Подтверждённое удаление теперь архивирует такие анализы в уникальную директорию
`~/Library/Application Support/PhotoCurator/legacy-learning-archives`. Архив содержит полную
проверенную SQLite backup, копии service-owned review/cache файлов и manifest с SHA-256.
Он не попадает под ротацию обычных backups. Только после проверки выполняются cascade и
очистка исходного кэша. При ошибке сохраняются проект и частичный архив для диагностики.
Снимок состава альбома не выдумывается, архив не импортируется в обучающий corpus.
Если snapshot существует, другие ошибки provenance по-прежнему блокируют операцию.

Проверка на изолированной копии настоящего каталога: прежняя ошибка воспроизведена;
удаление завершилось; 80 labels, 18 comparisons и 3468 image files сохранены и проверены.
Оригинальный проект и Photos не изменялись. Изолированная копия после успешной проверки
очищена, manifest и итоговые counts/hashes оставлены в evidence. Отдельные regression tests
проверяют отказ backup, отказ copy, symlink и сохранность проекта при каждой ошибке.

Evidence: `build/evidence/legacy-delete-2026-09-05/result.json`.
Исправленная app/DMG собрана, bundle проверен, app запущена; установленная версия не заменена.

`make lint` и все 306 тестов прошли.
