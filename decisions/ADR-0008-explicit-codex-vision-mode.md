# ADR-0008: Явный optional Codex Vision режим

- Status: Accepted

## Context

Локальные эвристики и Apple Vision не дают достаточно сильного понимания сюжета,
композиции и сравнительного качества похожей серии. При этом скрытая отправка личных
фотографий в cloud и неявное использование API недопустимы.

## Decision

Локальный анализ остаётся режимом по умолчанию. Пользователь может отдельно выбрать
экспериментальный `Codex Vision` и подтвердить предупреждение перед каждым новым проектом.
Только после подтверждения service-owned review-копии передаются установленному на этом Mac
официальному Codex CLI.

Приложение автоматически ищет CLI в PATH и внутри ChatGPT/Codex.app, проверяет
`codex login status` и разрешает запуск только при `Logged in using ChatGPT`. Авторизация
через API key блокируется, чтобы не создавать неожиданный usage-based счёт. Токены и лимиты
расходуются в ChatGPT/Codex workspace пользователя.

Codex запускается без shell, в read-only sandbox, с ephemeral session, без user config/rules
и со Structured Output schema. Результаты сохраняются после каждого bounded batch; ошибка
или отсутствие результата fail closed и не делает фотографию плохой.

## Consequences

- На другом Mac достаточно установить/обновить ChatGPT или Codex CLI и войти в ChatGPT.
- Это cloud-режим: изображения покидают Mac и обрабатываются по policy выбранного workspace.
- Режим зависит от доступности и лимитов Codex и может работать несколько часов.
- Стандартный локальный workflow, публикация plan/apply и ручной приоритет не меняются.
